# 🗳️ Face Recognition Voting System

A web-based **Face Recognition Voting System** designed to provide a simple and automated voting experience using **JavaScript, HTML, and CSS**.

The project includes voter registration, login, face-recognition functionality, voting, result viewing, and an admin interface.

---

## 🚀 Features

- 👤 Voter registration
- 🔐 User login
- 📸 Face recognition
- 🗳️ Online voting
- 📊 Voting results
- 👨‍💼 Admin panel
- 💻 Interactive web interface
- ⚙️ JavaScript-based application logic

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Web page structure |
| CSS3 | Styling and responsive interface |
| JavaScript | Application functionality |
| Face Recognition | Voter identification |
| Node.js / npm | Project package management |
